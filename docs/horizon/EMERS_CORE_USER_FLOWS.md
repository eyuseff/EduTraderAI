# EMERS Core User Flows

## 1. Purpose

Define conceptual flows before implementation.

## 2. Flow notation

Each row names trigger, preconditions, main path, alternatives, failures, visible status, confirmations, risk checks, evidence, recovery, and completion criteria.

## 3. General flow requirements

No order-related flow is complete merely because the application sent a request. Completion must reflect actual broker state.
