- Status: Release candidate preparation
- Trading mode: Paper-only

## Release summary

EduTraderAI v4.1 adds the deterministic one-share Connected Alpaca Paper
qualification boundary, durable local execution authority, fail-closed
reconciliation and integrity controls, event-publication observability, formal
performance gates, and review-only release-evidence automation.

The mandatory connected qualification completed on 2026-08-20 using exactly
one AAPL BUY/LIMIT/DAY Paper order at `314.22`, below the fresh observed best
ask of `317.40`. The order was acknowledged, observed, individually cancelled,
and reconciled to zero fill, no position, and no open orders. The retained
artifact is redacted and contains no credentials, account identifier, or broker
order identifier.

## Verification

Run the authoritative candidate gate:

```bash
make verify
```

The generated summary remains `HUMAN_REVIEW_REQUIRED`, is bound to the exact
source commit, and cannot create a tag, release, deployment, or broker action.

On the authorized operator workstation that retains the ignored connected
qualification artifact, build the combined local review bundle with:

```bash
python3 scripts/package_release_evidence.py \
  --manifest docs/releases/release-evidence-manifest-v4.1-connected.json \
  --output build/v4.1.0-rc1-connected-release-evidence.zip
```

The ordinary CI bundle deliberately excludes the workstation-only connected
artifact because that artifact is ignored by Git. The combined local bundle is
the release-review evidence source and remains subject to explicit human review.
