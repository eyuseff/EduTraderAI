# Polaris Phase 1 Scope

## Included screens

Home Dashboard, Opportunity Detail, Trade Plan Builder, Risk Review, Paper Approval, Paper Submission and Broker Status, Order Detail, Position Detail, Evidence drawer, degraded-mode panel, and emergency-stop panel.

## Excluded screens

Real authentication, live broker connections, real portfolio sync, real market data, mobile order submission, cloud deployment, notification delivery, EMERS Score, production web app, and frontend framework implementation.

## Design assumptions

The prototype uses a restrained dark interface, simulated euro values, visible Paper environment labels, calm language, risk-first hierarchy, and no final brand colors, fonts, or logos.

## Safety boundaries

No production modules are imported. No broker or data endpoint is contacted. No credentials are stored. No package manager is used. Browser refresh may reset the state.

## Current limitations

The prototype is client-side only, in-memory only, desktop-first, and uses simulated state transitions. It does not prove technical feasibility for production.

## Future prototype phases

Future phases may include validated visual design, mobile monitoring concepts, higher-fidelity accessibility review, engineering handoff, and user testing using simulated data only.
